# Проект  по работе с БД (базы данных)
## Описание
Проект "Курсовая работа" - написание функции на языке Python , отправка API запроса на HH.ru для получение ваканский

Модуль hh_api.py - в модуле расположен класс  инициализации , для коннекта с API и получением вакансий
Модуль db_manager.py - в модуле расположен класс с его методами для фильтрации API запроса 
Модуль utils.py - в модел расположены функции работы с базой данных 
## Установка
Клонируйте репозиторий: "SSH-ключ"" git@github.com:Dima-Gruzdev/Home_work_Course_2.git Установите зависимости: pip install -r requirements.txt

Использование
Откройте приложение с функцией на вашем компьютере В готовые классы в методы подставляйте свои данные для получения результаты Лицензия Этот проект лицензирован по [лицензии MIT] (LICENSE)
